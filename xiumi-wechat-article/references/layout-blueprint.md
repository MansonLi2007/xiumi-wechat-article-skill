# 排版蓝图：token、主题、区块、节奏、封面

## 1. 设计 token

| 项 | 值 | 说明 |
|---|---|---|
| 正文字号 | 16px | 15px 偏小，17px 显老 |
| 正文行高 | 1.8（28.8px） | 低于 1.6 挤，高于 2.0 散 |
| 字间距 | 0.5px | 中英混排更稳 |
| 段间距 | 16px | 用 `margin:0 0 1em` |
| 内容宽 | 677px | 微信正文区宽度，HTML 里写 `max-width:677px` |
| 左右边距 | 0 | 微信编辑器自带约 15px，别再叠 |
| 次要文字 | 15px / #8A8580 | 注释、来源 |
| 图注 | 13px / 居中 / 灰 | 上下留 8px |
| 小标题 | 19px / 700 | 行高 1.5 |
| 大标题 | 22px / 700 | 用于文内大标题（非平台标题） |
| 导语 | 17px / 行高 1.8 | 独立浅底块 |
| 圆角 | 10px（卡片）/ 4px（标签） | 全篇只用这两档 |
| 字重 | 只用 400 与 700 | 500/600 在部分安卓机渲染成 400 |

标点：中文用全角，数字与英文用半角，**不要手动加空格**，靠 letter-spacing 统一。

## 2. 三套主题

| token | paper（默认） | ink | mint |
|---|---|---|---|
| text | #2B2B2B | #1A1A1A | #1F2933 |
| sub | #8A8580 | #6B6B6B | #6B7A78 |
| accent | #B4552D | #C0392B | #0F766E |
| accent_soft | #F3E6DE | #F7E7E4 | #D7EDE9 |
| soft（浅底） | #FAF8F3 | #F5F5F5 | #F1F6F5 |
| card_bg | #FFFFFF | #FFFFFF | #FFFFFF |
| line | #E6E1D8 | #E4E4E4 | #DCE6E4 |

- **paper**：知识、职场、生活方式。暖，适合长文。
- **ink**：观点、评论、媒体。冷硬，对比强，适合短促有力。
- **mint**：工具、科技、效率。偏冷，适合教程与清单。

一篇只用一套，不要混。强调色全篇出现 ≤ 3 处重点（小标题序号、提示条、高亮）。

## 3. 区块规格（12 个）

| # | 区块 | 用途 | 结构要点 | 秀米对应 |
|---|---|---|---|---|
| 1 | 标题区 | 文内大标题 + 副标/日期 | 22px/700，副标 14px 灰 | 标题 tab |
| 2 | 导语 lead | 交代场景与收益 | 浅底 soft + 圆角 10 + 内距 16 | 卡片 tab（浅底卡） |
| 3 | 小标题 h2 | 分段视觉锚点 | 3px×32px 色条 + 19px/700 | 标题 tab（色条样式） |
| 4 | 正文段 | 主体 | 16px/1.8，段距 1em | 基础 | 
| 5 | 高亮 | 关键词 | `background:accent_soft;padding:0 2px` | 正文内高亮 / 组件→零件 |
| 6 | 引用 quote | 金句、他人观点 | 左 3px 色边 + 灰字 + 斜体 | 基础布局 + 左边框（无独立「引用」项） |
| 7 | 分割线 | 章节切换 | 细线 / 字符「· · ·」/ 短线居中 | 组件→分割线 / 分隔符 |
| 8 | 列表 | 并列信息 | 符号 span + 段，**不用 ul/li** | 正文符号，或 组件→零件 |
| 9 | 卡片 | 案例、要点、清单 | 白底 + 1px 描边 + 圆角 10 | 卡片 tab |
| 10 | 双栏 | 图左文右、两图并排 | `table role=presentation`，宽 48%/52% | 布局→左右图文 / 表格 |
| 11 | 图片+图注 | 一切配图 | 图 100% 宽，圆角 10，图注 13px 居中 | 图片→单图（开「说明」） |
| 12 | 结尾区 | 签名/关注/往期 | 虚线上边框 + 居中 14px 灰 | 组件→二维码 / 引导关注 / 文末互动 |

### 骨架示例（build_wechat.py 会生成等价结构）

小标题：

```html
<section style="width:32px;height:3px;background:#B4552D;margin:36px 0 12px;"></section>
<h2 style="margin:0 0 16px;font-size:19px;line-height:1.5;color:#2B2B2B;font-weight:700;">一、先看数据</h2>
```

卡片：

```html
<section style="margin:24px 0;padding:18px 16px;background:#FFFFFF;border:1px solid #E6E1D8;border-radius:10px;">
  <p style="margin:0 0 8px;font-size:17px;font-weight:700;color:#2B2B2B;">卡片标题</p>
  <p style="margin:0;font-size:15px;line-height:1.8;color:#4A463F;">卡片内容</p>
</section>
```

双栏（手拼时用，脚本不生成）：

```html
<table role="presentation" style="width:100%;border-collapse:collapse;margin:20px 0;">
  <tr>
    <td style="width:48%;vertical-align:top;padding-right:8px;"><img src="left.jpg" style="width:100%;display:block;border-radius:10px;"/></td>
    <td style="width:52%;vertical-align:top;padding-left:8px;font-size:15px;line-height:1.8;color:#4A463F;">右栏文字</td>
  </tr>
</table>
```

提示条：

```html
<section style="margin:20px 0;padding:14px 16px;background:#F3E6DE;border-left:3px solid #B4552D;border-radius:0 8px 8px 0;">
  <p style="margin:0;font-size:15px;line-height:1.8;color:#4A463F;">注意：正文里不要放外链，微信会拦。</p>
</section>
```

## 4. 节奏规则

- **首屏**：标题 + 一句价值 + 一张图，控制在 1.5 屏内。
- 每 300 字至少一个视觉锚点（小标题 / 图 / 引用 / 卡片 / 分割线）。
- 连续正文段不超过 5 段。
- 卡片与引用合计不超过全篇 30%，否则像 PPT。
- 全篇 3–6 个 h2；超过 6 个说明该拆成两篇。
- 结尾留白 ≥ 24px；最后一块不要是图片（容易被"阅读原文"压住）。

## 5. 封面

- 尺寸 **2.35:1**：900×383 或 1080×460；另出 **1:1** 1080×1080 作分享小图。
- 安全区：左右各留 8%，上 6%，**下 12%**（不同入口裁切不一致）。
- 主标题 ≤ 12 字，字号占画面宽度 ≥ 1/3；单色底 + 大字的点击率通常最稳。
- 缩到 200px 宽仍要能读：前景与背景对比 ≥ 4.5:1，别用细体。
- 不要放二维码、电话、密集小字。
- 1:1 版本单独排版，不要把 2.35:1 直接裁成方形。

## 6. 秀米组件速查（2026-10 实测菜单）

左侧竖栏：`图文模板` `图片素材` `图文收藏` `剪贴板` `我的图库` `团队素材` `音视频` `样刊模板`。
二级 tab：`标题` `卡片` `图片` `布局` `SVG` `组件` `热门` `推荐模板` + 圆形 `主题色` 按钮。

| 要做 | 点 tab → 菜单项 |
|---|---|
| 正文骨架 / 单列 | 布局 → 基础布局 |
| 左图右文 / 两栏 | 布局 → 左右图文（两图并排用 图片 → 双图） |
| 上图文下文字 | 布局 → 上下图文 |
| 表格型对齐 | 布局 → 表格 |
| 滑动图集 / 长插图 | 布局 → 左右滑动、上下滑动 |
| 自由拖拽 | 布局 → 自由布局 |
| 组合复用 | 布局 → 组合 |
| 单图 / 双图 / 三图 / 四图 | 图片 → 单图 / 双图 / 三图 / 四图 |
| 多图九宫格 | 图片 → 多图 |
| 圆形头像 | 图片 → 圆形图 |
| 满屏底图 | 图片 → 背景图 |
| 图片说明（图注） | 图片 → 单图 → 设置里开「说明」 |
| 分割线 / 点线 / 字符线 | 组件 → 分割线、分隔符 |
| 二维码 / 引导关注 | 组件 → 二维码、引导关注、公众号组件 |
| 序号 01/02 / 小零件 | 组件 → 零件 |
| 文末互动 / 投票 | 组件 → 文末互动 |
| 视频 / 表单 | 组件 → 视频、表单 |
| 标题卡 / 卡片 / 边框 | 标题 tab、卡片 tab |
| 动效 / 渐变字 | SVG tab（注意：复制到公众号会丢） |

子栏 `最近使用` 是效率入口；常改的主色用 `主题色` 统一，别逐块改色。菜单名随版本调整，按形状找别死记。
