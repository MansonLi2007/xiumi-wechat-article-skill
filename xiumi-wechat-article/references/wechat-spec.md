# 公众号平台限制与合规

## 1. 硬限制（可以写死的）

| 项 | 限制 | 备注 |
|---|---|---|
| 标题 | ≤ 64 字 | 列表页约 20 字截断，实际按 12–24 字写 |
| 摘要 | ≤ 120 字 | 不填时微信自动抓正文前 54 字左右，通常很难看 |
| 作者 | ≤ 8 字 | 显示在标题下方 |
| 封面 | 2.35:1 | 建议 900×383 或 1080×460 |
| 分享小图 | 1:1 | 朋友圈/会话分享用，需单独准备 |
| 正文内容区宽 | 677px | 编辑器实际渲染宽度，HTML 按此设计 |
| 图片格式 | jpg / png / gif | gif 体积大，慎用 |

**不要写死的**：正文字数上限、单篇图片张数上限——各入口提示不一致，以编辑器当场提示为准。

## 2. 编辑器行为（决定 HTML 怎么写）

- 剥离 `<style>` 标签、`class`、`id`、`<script>`、`<iframe>`；保留大部分**内联 style**。
- 图片 `src` 会被重写为自己的 CDN（mmbiz.qpic.cn）；外链图可能显示失败，最好从本地图复制粘贴让其自动上传。
- 外链只放行：公众号文章、小程序、视频号、少数白名单域名；其他 http(s) 链接会被去掉。
- `position:fixed`、`@media`、CSS 变量、动画一般无效。
- 表格保留，是双栏最稳的实现方式。
- 深色模式下，透明背景会被反色，浅底卡片要写不透明底色。

## 3. 内容合规

- **广告法**：禁用「最、第一、顶级、国家级、100%、永久、根治」等绝对化用语；对比广告需有依据。
- **医疗健康**：不得宣称疗效、治愈率；不得推荐处方药。
- **金融**：不得承诺收益（稳赚、保本、年化 X%）；需风险提示。
- **教育**：不得承诺保过、提分。
- **诱导行为**：不得「转发到 3 个群」「集赞」「助力解锁」「关注后回复」式强制。
- **版权**：图片、字体、音乐、视频都要授权；网图、影视截图、明星照风险最高。
- **肖像与隐私**：他人正脸、聊天记录、手机号、住址需授权或彻底打码。
- **AI 内容**：按平台当期规则考虑标注「本文含 AI 生成内容」。
- **原创声明**：转载必须授权并标注来源；洗稿会被投诉且影响权重。

## 4. 分发与数据（量级参考，账号差异极大）

- 标题与摘要进入「搜一搜」索引，写清楚关键词比写花哨更有用。
- 首图影响「看一看/推荐流」的点击，封面质量 ≈ 标题质量。
- 合集/话题/原创标影响长尾，发布时顺手勾。
- 订阅号打开率常见 3%–8%，完读率 20%–40%，在看率 0.5%–2%。低于这个区间先查标题、首图、开头 3 行。

## 5. 平台操作要点

- 一天群发次数有限（订阅号通常 1 次），定时群发前务必手机预览。
- 标题发出后不可修改（正文可小改，有次数限制），错字代价极高。
- 删除重发会损失已产生的阅读与推荐，慎重。
- 草稿箱是唯一的安全网：先存草稿，再群发。
