# 秀米（xiumi.us）落地操作

> 标注说明：**【实测】**= 2026-10-28 在 xiumi.us（账号等级 LV.1，Edge）真机操作确认；**【经验】**= 文档/社区/推断，未逐条验证。改版时以实测为准。

## 0 登录与入口

- `xiumi.us` 右上「登录」→ 跳 `xiumi.us/auth`：**邮箱或手机号 + 密码**登录；也可微信/QQ/微博扫码。会有滑块验证（腾讯 turing 验证码）。
- 首页「图文排版」三个入口：`挑选风格排版`（模板库）/ `图文新手指南` / `新建一个图文`。
- 【实测】点「新建一个图文」进编辑器，URL 形如 `https://xiumi.us/studio/v5#/paper/for/new/cube/0`。

## 1 编辑器结构【实测】

顶栏从左到右：`打开` `预览` `保存` `导出` `更多`；右侧 `授权设置` + 账号等级徽章。

画布首块（不在正文里，专门填元信息）：

```
[封面图]  [请输入图文的标题]
          [微信分享时的摘要，点击左侧图片改封面]
          关闭 | 开启   开启音乐视频等增强模式
          设置标签
```

画布底部常驻提示：`基础格式：字号 16，行间距 1.6，字间距 0，默认图`。

左侧竖栏（图标）：`图文模板` `图片素材` `图文收藏` `剪贴板` `我的图库` `团队素材` `音视频` `样刊模板`，底部 `收起`。

二级 tab：`标题` `卡片` `图片` `布局` `SVG` `组件` `热门` `推荐模板`，右端圆形按钮 `主题色`。
子栏：`最近使用` `样刊模板` `更多模板` + 搜索框（点某个 tab 后文案会变成 `在 '布局' 内搜索`）。

三级菜单（点 tab 弹出）【实测】：

| tab | 菜单项 |
|---|---|
| 布局 | 基础布局 / 表格 / 左右图文 / 上下图文 / 上下滑动 / 左右滑动 / 自由布局 / 组合 |
| 图片 | 基础图片 / 纯图片 / 单图 / 双图 / 三图 / 四图 / 多图 / 圆形图 / 背景图 / 滑动图片 |
| 组件 | 分割线 / 分隔符 / 公众号组件 / 引导关注 / 二维码 / 文末互动 / 零件 / 视频 / 表单 |

右下角缩放 `100%`；画布右侧浮动 `撤销 / 重做 / 帮助 / 设置`。

## 2 四条落地路线（按稳定性排序）

### A 秀米原生搭版（最稳，推荐给长期维护的号）

1. `新建一个图文`。
2. 首块填**标题**和**摘要**（摘要 ≤ 60 字，见 `wechat-spec.md`）。
3. 骨架用 `布局 → 基础布局`；图文并排用 `布局 → 左右图文`；两图并排用 `图片 → 双图`。
4. 卡片用 `卡片` tab；分割线、二维码、引导关注都在 `组件`。
5. 图片先传 `我的图库`，再插入。
6. 点 `主题色` 统一主色（改一次全篇跟随）。
7. `预览` 看手机版 → `保存`。
8. `导出` → 复制 → 公众号后台粘贴（见第 3 节）。

排版参数建议（`layout-blueprint.md` 的 token 可直接照抄）：正文 16px、行高 1.8、字距 0.5px、段距 1em、小标题 19px。**注意秀米默认行高是 1.6**，我们要的 1.8 需要手动改。

### B 复制我们生成的 HTML（最快）

1. 浏览器打开 `article-paste.html`（`--placeholder-images` 版）。
2. Ctrl+A → Ctrl+C。
3. 公众号后台 → 新建图文 → 编辑器里 Ctrl+V。
4. 文字版式会保留；图片位置是虚线占位块，逐张插入。
5. 补标题、作者、摘要、封面。

【实测】秀米「导出」后复制到公众号，SVG 动效和文字渐变会丢；普通内联样式（字号/颜色/行高/圆角/底色）能保留。

### C 导入 HTML 代码（能完整保留我们的版式，但卡会员等级）

1. `更多` → `导入HTML代码`。
2. 左侧文本框贴片段，右侧「预览效果」实时渲染。
3. 点 `导入`。

【实测】我们的 `article.html` 在这个预览里**基本无损**：浅底导语、色条小标题、加粗、行高、圆角卡片都还在。

【实测】但该入口下方标注「（该功能对等级会员VIP开放）」：测试账号 LV.1 点「导入」**没有反应**（弹窗不关、无报错提示），推断为等级不够。没开会员就用路线 B。

同一菜单还有 `导入Word/Excel/Markdown` 和 `导入公众号文章`。

【实测】`导入Word/Excel/Markdown` 弹窗原文：「支持 Word(.docx)、Excel(.xlsx)、Markdown(.md) 文件导入。注意：Word 格式会被清除；Excel 仅导入第一个工作表的表格和数据。」把我们的 `article.md` 直接喂进去的结果是：**整篇作为一个纯文本块塞进来**，`#`、`**`、`:::` 指令、frontmatter 全部原样显示为文字，没有标题层级也没有列表符号。所以这条路目前不能用来还原版式——除非先用脚本把 md 压成「无标记的纯文本」，再在秀米里手动上样式，得不偿失。要用秀米，就走 C（导入 HTML，需 VIP）或 A（原生搭）。

### D 同步到公众号（需授权，最省手）

1. `授权设置` → 弹窗「秀米授权管理」→ 绿按钮 `点击开始微信公众授权`。
2. 【实测】弹窗原文要点：授权必须**公众号管理员**扫码，运营者不能授权；运营者可以把二维码截图发给管理员，等对方扫码通过，期间不能关页面。
3. 【实测】弹窗还写明：只做「分享朋友圈的秀米链接」（非公众号文章）时**不需要**授权公众号，直接在图文编辑页开增强模式就能加音乐等。

## 3 导出与复制【实测】

点顶栏 `导出` **不是下拉菜单**，而是切到复制模式：画布顶部出现浅蓝提示条：

> 先 Ctrl+C（Mac：⌘+C）复制内容，然后 Ctrl+V（Mac：⌘+V）粘贴到公众号后台文章编辑器中。
> 部分 SVG 功能/文字渐变色无法复制，此时可使用 秀米插件 或者 同步功能。

- 这条提示不持久，刷新页面就消失。
- `更多` 菜单【实测】共 11 项：新建一个图文 / 导入 Word/Excel/Markdown / 导入公众号文章 / 导入HTML代码 / 另存一个图文 / 另存图文给其他用户 / 收集图片 / 生成长图/PDF/视频 / 生成贴纸图文 / 一键排版 / 将本图文设置为样刊。

## 4 图片

- 上传：左侧 `我的图库`（可建文件夹）；正文插图走 `图片 → 单图`。
- 公众号对图片有再压缩：正文图宽 900–1080px 足够，别传 4K 原图。
- 单图 ≤ 500KB 更稳（上限 2MB），用 `scripts/prep_images.py` 压。
- 封面在首块左侧那张图上传，按 2.35:1 裁；1:1 小图在公众号后台单独传。

## 5 常见坑

| 现象 | 原因 / 处理 |
|---|---|
| 复制到公众号后样式散架 | 用了 class 或外部 CSS。必须是内联 style；我们的脚本已经保证 |
| 图片变红叉 | 图片是本地路径或防盗链外链。微信只抓公网可访问地址；改用手动插图或先传 `我的图库` |
| 行距比设计稿紧 | 秀米默认 1.6，要在「基础格式」里改成 1.8 |
| 首行缩进两格消失 | 别打全角空格，用 `text-indent:2em` |
| 粘贴后整篇变成一段 | 粘贴前编辑器里已有文字，样式继承出错；先清空再粘 |
| 序号/圆点变成方块 | 用了 `<ul>/<li>`；改用带符号的段落 |
| 手机上看留白不对称 | 用了 `flex + gap` 或负 margin；改 `display:inline-block` + 定宽 |
| 同步后封面空白 | 封面要在公众号后台单独设，秀米同步不过去 |
| 深色模式文字看不清 | 浅底用了半透明色；改成不透明 hex |

## 6 发布前 60 秒清单

- [ ] 标题 ≤ 24 字（列表页约 20 字截断），摘要 ≤ 60 字且脱离标题能读懂
- [ ] 封面 2.35:1 主标题在安全区内（左右 8%、下 12%）
- [ ] 首屏有「标题 + 一句价值 + 一张图」
- [ ] 每屏至少一个视觉锚点（小标题/图/引用/卡片）
- [ ] 手机预览：没有长英文、长数字、括号造成的难看断行
- [ ] 外链只留公众号/视频号/小程序，其余删掉
- [ ] 原创声明、留言、合集按需勾选
- [ ] 结尾引导只有一个动作，不是三连口号
